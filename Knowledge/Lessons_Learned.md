# Lessons Learned

## 2026-09-05：1.1.1 模拟器验收与发布

主机通过不替代 Android 运行证据；隔离包逐字段升级证明也不替代正式证书和实际安装校验。系统语言与应用语言必须分别测试；快速 UI 自动化要确认输入法、动画与异步保存完成，不能把未触发按钮误报为产品错误。

- GitHub 将纯中文仓库标识规范化为空标识并最终显示为 `-`，Release 附件名也会剥离中文；因此仓库 URL 和 Release 文件名使用稳定的 ASCII 名称 `pocket-club-dues`，中文产品名保留在 README、仓库说明、Release 标题和仓库内 APK 文件名中。
- APK 为 57.34 MiB，虽然低于 GitHub 100 MB 单文件硬限制，但超过 50 MB 建议值；GitHub Release 更适合作为主要下载入口。
- 发布仓库应与源码工程隔离，避免脏工作树、构建缓存、签名材料和真实数据被误提交。
- 发布前实时确认仓库规范名称：旧地址可继续重定向，但新链接应采用 API 返回的当前 owner。
- 同包同签名和旧格式磁盘回归证明升级条件与兼容逻辑，不等于实际手机覆盖升级后的零丢失保证；保留本机设置优先的导入边界。
- 内部维护报告可能包含中间失败或过时“待重跑”状态，公开更新报告应只列最终证据，并明确尚未修复的问题。
