# 掌上部费

掌上部费是一款本地优先的 Android 部费与收支记录应用。本仓库用于分发正式安装包和公开更新报告，不包含应用源码、签名私钥或用户账本数据。

## 当前版本

**1.1.1 / 168**，包名 `com.pocketledger.app`，正式签名、非 Debug，与 1.0.3、1.1.0 使用同一证书。最低 Android 12 / API 31；本轮验收环境为本机 Android 16 / API 36 模拟器，不代表全部 Android 版本或厂商手机已验收。

## 下载与安装

从 [GitHub Release v1.1.1](https://github.com/YunkaiYM/pocket-club-dues/releases/tag/v1.1.1) 下载 `pocket-club-dues-1.1.1.apk`，或使用仓库中的 [1.1.1 APK](Releases/掌上部费-1.1.1.apk)。两者为相同文件。

升级前请先在应用内导出备份，再直接覆盖安装。**不要卸载旧版或清除应用数据。** 同包名、同签名、递增版本条件已核验，正式 1.1.0 → 1.1.1 模拟器覆盖安装通过。生成测试账本的旧隔离版实际升级与旧 ZIP 导入也已通过，未使用用户真实账本进行测试。其他签名、设备故障或缺失文件不在无损保证范围。

旧 ZIP 导入继续采用本机同名设置优先，不等于覆盖恢复新设备的全部外观和偏好。历史 [v1.1.0](https://github.com/YunkaiYM/pocket-club-dues/releases/tag/v1.1.0) 和 [v1.0.3](https://github.com/YunkaiYM/pocket-club-dues/releases/tag/v1.0.3) 保留；保留旧包不代表支持无损降级。
