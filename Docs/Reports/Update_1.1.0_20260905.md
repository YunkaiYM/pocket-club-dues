# 掌上部费 1.1.0 更新报告

日期：2026-09-05。正式版：`1.1.0 / 167`。状态：`主机验证通过 / 真机验收待完成`。

本报告为公开发布版，保留功能、升级说明、最终验证结果和已知问题，不包含本机路径、签名凭据或用户账本数据。

## 功能更新

### 收入记账开关

在“我的 → 记账设置 → 收入设置”中可关闭收入记账。关闭后隐藏普通收入登记入口、阻止新的普通收入登记，统计界面只显示支出相关维度。历史收入和已形成的账户余额不会因此删除或重算，重新开启后可继续使用。

### 两套独立的五档反馈规则

“五档反馈规则”可从记账设置或外观与个性化进入。反馈方式与收入开关独立：即使收入功能开启，也可选择仅按当日支出金额反馈。

| 反馈方式 | 默认四个分界值 | 判断依据 |
|---|---|---|
| 仅按当日支出金额 | 50 / 100 / 150 / 200 元 | 当日已保存的支出总额 |
| 当日支出 / 日均收入比例 | 50% / 80% / 100% / 120% | 当日支出相对于登记周期日均收入的比例 |

四个严格递增的正数形成五档，等于分界值时归入前一档。两套门槛独立保存，金额最多两位小数；无效输入会被拒绝。切换反馈方式前需先保存或撤销未保存的门槛修改。

金额模式使用“支出很少／支出较少／支出适中／支出较多／支出偏高”，继续对应原五个媒体槽，改名不会清除已有自定义图片和音频。关闭收入时暂时强制使用金额模式，但保留原先选择，便于重新开启收入后恢复。

### 月、年收入的日均计算

旧统计页已有周期平均收入计算，但旧每日反馈仅读取当天登记的收入。本版已将比例反馈接入“收入登记周期”设置，而不是使用统计页当前选中的周期。

- 汇总登记周期内的普通收入和额外收入，除以实际天数，再四舍五入到分。
- 月登记按当月 28/29/30/31 天；年登记按 365/366 天；周登记采用设置中的周首日。
- 例：月收入 3100 元且当月 31 天，日均收入为 100 元；闰年年收入 36600 元，日均收入为 100 元。
- 反馈卡展示所采用的日均收入、当日支出和比例。

这是“支出 / 日均收入比例”，不是按“当日净收入金额”分档，也不改写真实现金流净额、交易日期或账户余额。

## 修复与体验改善

- 修复完成当日登记后，打开补记、保存补记或完成补记时反复播放反馈语音的问题。现在仅在“未完成 → 成功完成”的明确操作中产生一次播放事件；补记跨档、重新进入页面及恢复已完成状态不会自动重播。主动取消完成后再完成可再次触发。
- 收入或支出正在保存时禁止完成登记，避免反馈读取尚未保存的数据；未保存的金额、备注和附件会得到提示。
- 拒绝普通记录重复 ID（含已删除记录标识），避免重复影响余额；修复备用存储中设置重启丢失的问题。
- 主导航保留可保存的页面状态，增加 180 毫秒轻量进入动画，整理反馈规则入口及未保存修改的交互。
- 本轮新增设置文案提供中文、英文和日文。

## 掌上部费特色保留

应用名称和图标、指定开屏与两条启动音频、五档默认图片和音频、限定素材库、各页面背景、点击特效及隐藏 0/8/2/1 解锁保持不变。147 项品牌资源对比一致，44 条 WAV 仍以未压缩方式封装。

收入开关、反馈方式及门槛属于业务设置；“恢复默认外观”不会重置这些业务设置。

主机测试已验证：旧形态数据库关闭后由新仓储重开，账本及旧设置保留，仅补齐三个新设置；旧版 ZIP20 格式导入持久数据库并重开后，收入、支出、账户余额、分类与完成状态保留。关闭收入不会阻止历史收入导入。

这些测试使用生成的旧格式数据，不是用户真实账本，也不是实际运行历史 APK 完成手机升级。**本轮尚未执行真机覆盖安装及安装后的数据保留验收，不能承诺所有设备和备份场景都已经实测。**

导入沿用本机同名设置优先，包括本机已经初始化的默认值；旧备份能够导入账本，不等于会覆盖恢复全部外观和设置。自定义媒体、附件还受原有资源完整性和读取权限约束。
