# 掌上部费 1.1.1 更新报告

日期：2026-09-05。版本：`1.1.1 / 168`。

本轮维护已通过主机回归、本机 Android 16 模拟器有界验收及正式签名校验。以下区分实际完成的验证与未覆盖场景。

## 本次改进

本次为恢复安全和操作体验维护，不改变现有记账规则及掌上部费的独立特色。

### 数据恢复与备份

- “恢复全部用户设置”保留账本清空恢复所需的本机事务信息、首次引导完成状态和品牌初始化状态；重置后可按现有条件立即撤销。
- 修复清空后重新启用余额功能可能覆盖待恢复统一账户余额的问题。恢复时同时保留清空后的新记录和余额变化，金额合计超出整数范围时整笔拒绝，不进行部分恢复。
- 清空、恢复及到期清理覆盖相关余额校正、债务和附件载荷；附件仅在确认不再被引用时按明确清单清理。并发发布中的附件采用保守延后清理，不承诺立即物理擦除。
- ZIP 导出和导入采用相同的安全限额。超限导出在打开目标文件写入前拒绝，避免生成无法回读的包或提前截断已有备份。
- 导入完成提示汇总全部实体类型，修复部分新增或跳过数量未计入的问题；不改变原有合并规则。

### 操作与设置

- 外观与个性化拆为五组：名称与图标、页面背景、开屏画面与音频、每日反馈媒体、点击效果与音效。各组保留自己的滚动位置。
- 记账设置直接显示收入启用状态及当前实际反馈方式；“恢复全部用户设置”与“仅恢复外观默认值”明确区分。
- 编辑反馈门槛后返回，会提示保存、放弃或继续编辑。各输入框明确说明错误和五档完整范围，分界值仍归入前一档。
- 外观滑条拖动时预览数值，松手后应用并保存，减少连续落盘。
- 修复通知到达已有应用实例时未正确切换目标页面的问题。
- 修复记账日期误用系统语言的问题：中、英、日日期现在跟随应用语言，而非手机系统语言。
- 异步保存只清理本次提交的草稿，不清空保存期间的新修改；表单比较包含金额、备注、日期、分类、账户和分摊等上下文。
- 跨日后空白默认表单跟随今天；已有草稿会提示选择日期，用户主动指定的历史日期不自动跳走。前台日期检查粒度为 60 秒，后台返回立即刷新。
- 隐藏点击音频不再跟随短暂视觉特效被提前释放；关闭音效或转后台会停止播放，再次开启只响应新点击。声音最多并发 16 个，超出时丢弃新声音，不抢断已有声音。

## 掌上部费特色与业务规则保留

- 名称、图标、指定开屏、默认背景、五档反馈图片与音频、限定素材库、点击乐器特效及 `0 / 8 / 2 / 1` 连续隐藏解锁不变。
- 147 项品牌资源与正式 1.1.0 字节一致，44 条 WAV 仍未压缩封装。音频继续使用媒体音量，应用不自动调高系统音量。
- 收入开关独立于反馈方式：收入开启时仍可选择仅按支出金额反馈；关闭收入不会删除历史记录。
- 比例反馈继续使用收入登记周期的实际日均收入，月、年按实际天数计算；不改写现金流净额或真实账户余额。
- 反馈方式及门槛属于业务设置，“仅恢复外观默认值”不会重置这些设置。

## 升级与旧备份说明

本版数据库仍为 Room 14，ZIP 备份格式仍为 20。正式包名为 `com.pocketledger.app`。请先在应用内导出备份，再直接覆盖安装正式 APK；**不要卸载旧版或清除应用数据。** 同签名覆盖升级不要求主动清空账本，但不承诺所有设备故障场景均不会丢失数据。

旧 ZIP 导入继续采用本机同名设置优先；导入账本不等于覆盖恢复新设备上的全部外观和偏好。自定义媒体、附件仍取决于原有权限与文件完整性。本机清空恢复事务资料不进入便携备份，不应把 ZIP 当作待恢复批次的完整复制。

如果旧版已覆盖并丢失待恢复账户的原余额，而且没有其他备份，新版无法凭空恢复该值。保留历史安装包不代表支持无损降级。

## 已知边界

- 既有跨业务极端金额整数溢出仍需专项处理。本轮只增加清空恢复合计的原子保护，不代表所有余额运算已完成全局修复；避免使用接近整数极限的不合理金额。
- ZIP20 单条目上限 10 MiB、总解压载荷上限 96 MiB。超限账本会明确拒绝导出，不静默删减内容；分片或流式大账本备份尚未实现。
- 完整三语言无障碍、全部尺寸矩阵、低存储、故障注入、长期稳定性、自然厂商后台时序及第二物理设备迁移尚未全部验收；未覆盖项目保留其原有状态。
- 本次修复经过对应回归，但不等于宣称全程序没有其他缺陷。
